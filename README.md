# Deriv Digit Analyzer 🚀

A high-performance real-time quantitative trading and digit analysis terminal for **Deriv Synthetic Indices** (Volatility Indices 10/25/50/75/100, 1-Second variants, and Crash/Boom).

Built with **React 19**, **TypeScript**, **Vite**, and **Tailwind CSS v4**.

---

## ✨ Features

- **⚡ Real-time High-Frequency WebSocket Feed**: Direct streaming from Deriv API WebSocket (`wss://ws.derivws.com/websockets/v3`) with zero polling latency and automatic multi-endpoint failover.
- **📊 Descriptive Digit Frequency Analysis**: Live 0–9 digit frequency distributions calculated over customizable windows (100, 300, 500 ticks) compared against the theoretical 10.0% uniform baseline.
- **🔥 Statistical Signal Matrix & Dormancy Streaks**: Overrepresented (Hot) vs. Underrepresented (Cold) digit variance flags with streak/dormancy counters.
- **🎯 Tactile Trade Execution Terminal**: Place Digit Match, Differ, Over, and Under contracts with live payout proposals, quick-stake presets, and client-side risk guardrails.
- **📈 Offline Execution Journal**: IndexedDB persistence for all trade executions, tracking overall win rates and signal-aligned strategy performance.
- **💎 Luxury Trading Terminal UI**: Cyber/fintech dark theme with neon badges, gradient area sparklines, glassmorphism panels, and smooth micro-animations.

## 🚀 Quick Start

### Prerequisites
- Node.js (v18+)
- npm

### Installation & Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/FADHY78/Deriv-Digit.git
   cd Deriv-Digit
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173/` in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```

## 🔑 Authentication Options

1. **API Token (Recommended for Localhost)**:
   - Generate a token at [Deriv API Token Settings](https://app.deriv.com/account/api-token) with **Read** and **Trade** scopes.
   - Paste into the API Token tab for instant direct connection.
2. **Instant Sandbox Mode**:
   - 1-Click practice terminal streaming live real-time Deriv Volatility market ticks with a virtual $10,000 balance.
3. **Deriv OAuth**:
   - 1-Click OAuth login for production domains or custom registered App IDs on [api.deriv.com](https://api.deriv.com).

Deriv synthetic indices are generated by an independently audited and certified cryptographic Random Number Generator (RNG). Past digit distribution is statistically independent of future ticks. Signals and deviation metrics are descriptive historical tools, not predictive guarantees.
